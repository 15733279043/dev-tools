关于这个 JSON 格式化工具

这是一个免费的在线 JSON 工具，面向开发者、接口测试人员和数据工程师。它把压缩在一行的 JSON 按层级缩进美化，让数据结构一目了然；也可以反向压缩成单行，减少传输体积。内置语法校验帮助你快速定位缺少逗号、引号不匹配等常见错误，还能一键按 Key 字母顺序排序，方便对比两份配置。

主要功能

  • 格式化 / 美化：自动补齐层级缩进，支持 2 空格、4 空格或 Tab。
  • 压缩：移除多余空白，减小体积，适合接口传输。
  • 语法校验：基于浏览器原生 JSON 解析器，错误提示含具体位置。
  • Key 排序：递归对对象的所有层级按 Key 字母序排列，便于 diff 对比。
  • 语法高亮：区分键名、字符串、数字、布尔值、null，阅读更轻松。
  • 本地处理：所有操作在浏览器内完成，接口数据也不用担心泄露。

常见用途

API 接口返回值调试、Postman / Apifox 响应查看、配置文件（package.json、tsconfig.json）整理、前后端数据字段核对、日志中的 JSON 提取与检查等。

常见问题

我的 JSON 数据会被上传或保存吗？

不会。格式化、压缩、校验全部通过浏览器本地 JavaScript 完成，页面不发起任何上传请求。

支持带注释的 JSON（JSONC）吗？

不支持。本工具处理标准 JSON 规范，带注释或尾随逗号的内容需先清理。JSON5 / JSONC 的特殊语法会导致校验失败。

超大数字为什么会精度丢失？

JavaScript 的 Number 类型安全整数上限是 2^53-1，超过该值的整数在解析时可能丢精度。如需处理超大整数，建议在业务层用字符串传递。

中文会变成 \uXXXX 乱码吗？

不会。本工具保留中文原样输出，不做 Unicode 转义。

Key 排序会改变数据含义吗？

不会。JSON 对象本身是无序的键值对集合，排序只影响显示顺序，不改变数据内容。数组顺序会原样保留。
