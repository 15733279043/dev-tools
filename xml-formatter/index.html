关于这个 XML 格式化工具

这是一个免费的在线 XML 工具，面向开发者、测试工程师和数据对接人员。它把压缩在一行的 XML 按层级缩进美化，让结构一目了然；也可以反向把带缩进的 XML 压缩成单行，减少传输体积。同时提供语法校验，帮助你快速定位标签未闭合、属性缺引号等常见错误。

主要功能

  • 格式化 / 美化：自动补齐层级缩进，支持 2 空格、4 空格或 Tab。
  • 压缩：移除标签之间的空白，减小文件体积。
  • 语法校验：基于浏览器 XML 解析器，发现结构错误并提示位置。
  • 语法高亮：区分标签、属性、文本、注释、CDATA，阅读更轻松。
  • 本地处理：所有操作在浏览器内完成，敏感配置文件也不用担心泄露。

常见用途

接口返回的 XML 报文调试、Spring / Android 配置文件整理、SVG 与 XSD 文件查看、SOAP 消息排查、RSS / Sitemap 检查等。

常见问题

我的 XML 会被上传或保存吗？

不会。格式化、压缩、校验全部通过浏览器本地 JavaScript 完成，页面不发起任何上传请求。

为什么校验提示成功但格式化结果看起来变了？

格式化会规范化标签之间的空白与缩进，并合并纯文本节点的空白，这是正常行为，不会改变 XML 的语义结构。

支持多大的文件？

建议 5 MB 以内。超大文件受浏览器内存限制，可能出现卡顿。

可以处理 SVG / XHTML 吗？

可以，它们本质上都是 XML。自闭合标签与属性会被正确保留。
